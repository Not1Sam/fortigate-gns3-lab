\chapter{Câblage Complet}
\label{annexe:cablage}

\subsection{WAN}

Tous les FortiGate sont connectés au WAN via Switch1 :
\begin{itemize}
    \item NAT1 (virbr0) → Switch1 → FGT-Primary port1
    \item NAT1 (virbr0) → Switch1 → FGT-Secondary port1
    \item NAT1 (virbr0) → Switch1 → FGT-Primary-HA port1
    \item NAT1 (virbr0) → Switch1 → FGT-Secondary-HA port1
\end{itemize}

\subsection{LAN1}

\begin{itemize}
    \item FGT-Primary port2 → OVS-LAN1 eth0
    \item OVS-LAN1 eth1 → PC1
    \item OVS-LAN1 eth2 → appServer-1
    \item OVS-LAN1 eth3 → PostgreSQL-1
    \item OVS-LAN1 eth4 → Docker Router eth0
\end{itemize}

\subsection{LAN2}

\begin{itemize}
    \item FGT-Secondary port2 → OVS-LAN2 eth0
    \item OVS-LAN2 eth1 → Alpine-DHCP
    \item OVS-LAN2 eth2 → Ubuntu Desktop
    \item OVS-LAN2 eth3 → Traffic-Gen-1
    \item OVS-LAN2 eth4 → Grafana-1
    \item OVS-LAN2 eth5 → Prometheus-1
    \item OVS-LAN2 eth6 → Docker Router eth1
\end{itemize}

\subsection{HA Heartbeat}

\begin{itemize}
    \item FGT-Primary port3 → FGT-Primary-HA port3 (169.254.0.1/30)
    \item FGT-Secondary port3 → FGT-Secondary-HA port3 (169.254.0.2/30)
\end{itemize}
