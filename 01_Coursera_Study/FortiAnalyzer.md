## 📝 Logging & Supervision

### 📊 Log Severity Levels
| Level | Name | Description |
| :--- | :--- | :--- |
| **0** | Emergency | System unstable or unusable |
| **1** | Alert | Immediate action required (e.g. HA Failover) |
| **2** | Critical | Critical security event (e.g. Virus blocked) |
| **3** | Error | Minor service failure |
| **4** | Warning | Resource warning |
| **5** | Notification | Normal state change (e.g. VPN tunnel up) |
| **6** | Information | Standard connection log |
| **7** | Debug | Debug messages |\n
